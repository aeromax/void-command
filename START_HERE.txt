VOID COMMAND

1. Install Node.js 20 or newer from https://nodejs.org.
2. Unzip this package.
3. Open a terminal in the void-command folder.
4. Run: npm run serve
5. Open: http://localhost:4173

No npm install is needed. Keep the terminal open while playing.
Press Ctrl+C in the terminal to stop.

See README.md for controls. Run npm test to verify the simulation.
The complete game and bundled Three.js library are in dist/.
